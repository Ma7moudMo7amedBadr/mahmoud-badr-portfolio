# Mahmoud Mohamed Badr — Portfolio

Professional, high-performance portfolio website for **Mahmoud Mohamed Badr**, a Machine Learning Engineer specialized in **Cybersecurity**.

## Overview

The site is a single-page, mobile-first portfolio designed around:

- **Clear positioning**: ML Engineer focused on incident response, vulnerability hunting, and AI-driven detection pipelines.
- **Concise storytelling**: About, Expertise (skill matrix), Projects (problem–solution–impact), Certifications, and Contact.
- **Dark cyber theme**: Subtle gradients, neon accents, and unobtrusive animations for a focused, professional feel.

## Structure

- `index.html` — Main portfolio page and content.
- `styles.css` — Dark, cyber-inspired responsive layout and theming.
- `script.js` — Small enhancements (mobile navigation toggle, dynamic year).

External assets:

- Google Fonts (`Space Grotesk`)
- Font Awesome icons via CDN

## Running Locally

No build step is required — this is plain HTML/CSS/JS.

1. Open `index.html` directly in your browser, or
2. Serve the folder using any static server (for example, with Node.js installed):

```bash
npx serve .
```

Then open the printed local URL (often `http://localhost:3000`) in your browser.

## Customization

- Replace the project screenshot placeholders in the **Projects** section with real images if available.
- Adjust copy in the **About**, **Expertise**, and **Projects** sections to reflect new work or focus areas.
- Update contact details or add additional social profiles in the **Contact** section as needed.
